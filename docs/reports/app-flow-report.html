Navigation rules that matter

Tabs define the main app

Home is the launch destination. Today (Home), Workouts and History share bottom navigation. Profile opens from the Today avatar and has a back action. The bottom bar disappears on detail pages, Player, Completion and the Devices overlay.

Starting is a separate action

Library workout → Preview → Player → Play. Today Open workout and FTP Ramp Test → Player → Play. Device setup is reached from Home; the player has no Devices shortcut or mandatory connection gate.

Saving is explicit

Completion → Save stays on Completion. Done returns Home after a successful save. Discard returns Home. A ride with no samples cannot be saved and can leave via Done.

Details to consider in the next cleanup

Back from Completion

There is no custom Back interception on Completion. Android Back can return to the previous Player, unlike Done/Discard, which return Home. The report describes this existing behavior.

End confirmation stays live

Opening “End workout?” does not pause the ride. Cancel/dismiss returns to the existing running or paused state. Notification Stop ends directly without that dialog.

Two independent decisions

Accept/Discard FTP changes the ramp-test result decision, separately from Save/Discard of the ride. Discard after a local Save removes that local session, but does not reverse an external upload.
